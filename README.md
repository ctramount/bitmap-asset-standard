# Bitmap Asset Standard

An open standard for minting and owning NFTs in the Bitmap ecosystem on Bitcoin, as inscriptions read through ord. It covers collection membership, burns, mint guidance, optional add-ons and optional profiles for apps and worlds.

- **Specification:** [SPEC.md](SPEC.md) (a PDF copy is included in this repository)
- **Status:** Version 1.0, first public release, November 4, 2026
- **License:** [CC0 1.0 Universal](LICENSE) (public domain dedication), for the specification text and the reference code
- **Feedback:** open a GitHub issue in this repository

## Reference code

Reference code is optional example code, inscribed on Bitcoin, that shows one way to follow the standard (SPEC.md, section 12.4). It is not yet inscribed. Inscription IDs will be listed in this repository when published. The standard itself is the text of SPEC.md.
